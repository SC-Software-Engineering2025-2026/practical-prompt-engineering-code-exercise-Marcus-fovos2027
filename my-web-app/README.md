# My Web App

This is a simple web application that allows users to save and delete prompts. The application features a clean and professional light mode design.

## Project Structure

```
my-web-app
├── index.html
├── css
│   └── styles.css
├── js
│   └── script.js
└── README.md
```

## Getting Started

To run this application, you will need to have Live Server installed in your development environment. Follow these steps to set up and run the application:

1. **Clone the repository** or download the project files to your local machine.

2. **Open the project folder** in your code editor.

3. **Install Live Server** if you haven't already. You can do this by searching for "Live Server" in the extensions marketplace of your code editor.

4. **Open the `index.html` file** in your code editor.

5. **Start Live Server** by right-clicking on the `index.html` file and selecting "Open with Live Server" or using the command palette.

6. Your default web browser will open, displaying the application. You can now enter prompts, save them, and delete them as needed.

## Features

- **Save Prompts**: Users can enter a title for their prompt and save it.
- **Display Saved Prompts**: All saved prompts are displayed in a dedicated section.
- **Delete Prompts**: Users can delete prompts they no longer need.
